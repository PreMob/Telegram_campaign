1. YOUR ROLE

Act as a senior full-stack engineer, software architect, product manager, UI/UX designer, database engineer, QA engineer, and DevOps engineer.

Build a complete, working web application called Telegram Audience Growth Platform.

Do not stop at writing a plan, creating mockups, or generating code snippets. Inspect the development environment, create the project files, implement the application, run it, test it, fix errors, and provide clear instructions for launching it.

2. BUSINESS CONTEXT

I have a Telegram public channel and a database of approximately 40,000 phone numbers.

I want a centralized platform that helps me:
- Import and manage my contact database.
- Validate and deduplicate phone numbers.
- Record consent and communication preferences.
- Create and manage Telegram acquisition campaigns.
- Generate campaign-specific Telegram invitation links.
- Track Telegram membership events and attribute joins to campaigns when supported by available evidence.
- Identify eligible contacts whose membership status is unknown or who are verified non-members.
- Run compliant follow-up campaigns through authorized communication providers.
- Monitor conversions, failures, campaign costs, and net channel growth.
- Manage everything through a modern web dashboard.

CRITICAL CONSTRAINT:
Telegram does not provide a general-purpose Bot API method to find every Telegram account from arbitrary phone numbers or automatically add a list of 40,000 people to a channel. Do not implement scraping, unauthorized account discovery, unsolicited mass messaging, or attempts to bypass Telegram's restrictions.

Build the system around official Telegram Bot API capabilities, voluntary joining, trackable invitation links, verified membership events, and authorized outreach integrations.
